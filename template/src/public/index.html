Quick Start Guide

Welcome to Phantasm 8.3. This toolkit is designed to help you create and manage Docker-based projects with ease.

01 Initialize a New Project

Use the provided script to clone the boilerplate and set up your project environment.

./create-project.sh <PORT> <PROJECT_NAME>

Example: ./create-project.sh 8008 my-cool-app

02 Development Workflow

Once created, your project will be available in the projects/ directory.

cd projects/8008-my-cool-app
# Place your source code in src/
# Start the containers
docker compose up -d --build

03 Infrastructure Access

All projects are connected to the infra network, allowing them to communicate with shared services like MariaDB or MQTT.

Panduan Cepat

Selamat datang di Phantasm 8.3. Toolkit ini dirancang untuk membantu Anda membuat dan mengelola proyek berbasis Docker dengan mudah.

01 Inisialisasi Proyek Baru

Gunakan script yang tersedia untuk menduplikasi boilerplate dan mengatur lingkungan proyek Anda.

./create-project.sh <PORT> <NAMA_PROYEK>

Contoh: ./create-project.sh 8008 aplikasi-keren

02 Alur Kerja Pengembangan

Setelah dibuat, proyek Anda akan tersedia di direktori projects/.

cd projects/8008-aplikasi-keren
# Letakkan source code di dalam folder src/
# Jalankan container
docker compose up -d --build

03 Akses Infrastruktur

Semua proyek terhubung ke jaringan infra, memungkinkan komunikasi dengan layanan bersama seperti MariaDB atau MQTT.

Project Structure

Phantasm 8.3 follows a modular structure for maximum efficiency:

  • infra/: Core services (MariaDB, MQTT, etc.)
  • projects/: Your individual applications
  • projects/8001-boilerplate: The base template for new projects

Struktur Proyek

Phantasm 8.3 mengikuti struktur modular untuk efisiensi maksimal:
